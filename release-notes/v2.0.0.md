### Added
- HTTPS for every alias, with the certificate issued automatically when you switch it on.
- Alias changes are applied for you, coalesced behind a single administrator prompt instead of a manual apply step.
- You can uninstall everything from inside the app.
- An offline page for aliases whose dev server isn't running, instead of a bare connection error.
- Stack detection for the projects you add.
- An option to start the app at login.
- A rescan action to pick up projects again without restarting.
- Onboarding opens on its own the first time you launch the app.
- A website with a download page, an FAQ, and the list of releases.

### Fixed
- A renewed certificate now actually reaches the wire; previously the old one stayed in use.
- The forwarder failed to start when the app was launched behind the administrator prompt.
- Paths inside the packaged app resolved as if it were a development build.

### Changed
- Aliases now default to the `.test` suffix and `.local` is gone, removing the roughly five seconds it added to every request.
- Traffic is handed off by a raw TCP forwarder rather than the previous HTTP proxy.
- The interface is a single page — project grid, drawers (now wider) and status in the corner — and the navigation rail is gone.
- A root helper means you are asked for administrator rights once per launch rather than on each change, and the dashboard button drives that prompt through the tray.
- The tray menu lists only aliases that are actually live.
